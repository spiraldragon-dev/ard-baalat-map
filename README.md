# Ard Ba'alat Map

An interactive map of toponym survivals and worldbuilding locations on the Lebanese landscape.

**Live map:** https://spiraldragon-dev.github.io/ard-baalat-map/

Built with [Leaflet](https://leafletjs.com/) and [OpenTopoMap](https://opentopomap.org/).

## About

Ard Ba'alat is a worldbuilding project by [Samer Beyhum](https://astartecore.com/). This map renders locations from the project against real Lebanese topography, layering real-world etymological evidence (Phoenician, Aramaic, Syriac, Canaanite toponym survivals) with in-world worldbuilding locations.
